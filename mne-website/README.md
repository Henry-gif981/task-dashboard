# The Multinational Enterprises — website and slide deck

Website presenting the paper **"Multilateral Investment System and Multinational
Enterprises – Topic: The Multinational Enterprises"** (Group 4, National Economics
University – AEP, Investment Economics 65; lecturer Nguyễn Thị Mai Hoa; Ha Noi,
10/2026), **version 2** of the paper (`MNEs - Nhóm 4 (1).pdf`).

One DOM, three views, always in sync:

* **scroll view** — the 63 slides one under another, each a 1920×1080 stage zoomed to the
  column (reflowed into a reading layout below 760 px);
* **presentation** — one slide per screen with PowerPoint-style **Morph** transitions
  (see [MORPH.md](MORPH.md));
* **print / PDF** — one slide per 1920×1080 page.

Visual style: the vintage engraving deck *Mẫu đabien.jpg* (cream paper alternating with
blue watercolour, giant small-caps titles with cut-out engravings). See [DESIGN.md](DESIGN.md).

## Run

Requires Node.js ≥ 20.11. No dependencies to install.

```bash
cd mne-website
npm start            # → http://localhost:5173   (Present button or P key)
```

Single file that opens without a server: `python3 tools/standalone.py` → `dist/mne-website.html`.

## Content

* `content/content.md` — the full text of paper v2 (verbatim; tables broken by page breaks merged).
* `content/CHANGELOG.md` — what changed from paper v1 to v2, section by section (keep / edit / add / delete).
* `content/ISSUES.md` — contradictions, missing citations and calculation checks for the authors;
  the three clear cross-reference errors are corrected on the site and listed there.
* `SLIDES.md` — slide list (title, content, morph keys), generated by `node tools/slides-md.mjs`.
* Text added by the website (contents slide, key-number tiles, card labels, chart axes,
  "(cont.)", list of figures, extra abbreviations…) is marked `data-web` in `index.html`.

## Presenting

Present button, **P**, `index.html?present` or `index.html#/12` (starts on slide 12).
→ / Space / PageDown / Enter / click / swipe = next, ← / PageUp = previous, Home / End,
**F** full screen, **G** overview, **Esc** exit. The bottom bar sets the effect
(**Morph | Fade | Off**) and the duration (0.5–2 s); both are remembered. To change the
default duration or easing: `--morph-ms` / `--morph-ease` in `css/style.css` (details in MORPH.md).

## Tests (server running)

```bash
npm i -D playwright                    # once (or set PLAYWRIGHT_PATH to a global install)
node scripts/verify-content.mjs        # paper v2 PDF ↔ DOM: missing / extra sentences, cells, references
node tools/check-layout.mjs            # every slide fits 1920×1080, nothing clipped, body ≥ 22 px, tables ≥ 18 px
node tools/test-morph.mjs              # morph frames at 50 %, back, rapid presses, FLIP fallback, reduced motion
node tools/check.mjs                   # console errors, horizontal overflow (390/768/1440), WCAG AA contrast
node tools/screens.mjs                 # screenshots 1920×1080, 1440×900 (presentation) and 390 px (scroll)
node tools/export-pdf.mjs              # dist/mne-website.pdf, one slide per page
```

`verify-content` reads `reference/paper-v2.pdf` (not committed; put the paper there or pass
its path) and needs `pdftotext` (poppler-utils).

## Folder structure

```
mne-website/
├── index.html            # all slides (semantic HTML, data-morph keys)
├── css/style.css         # tokens, stage, components, mobile reflow, presentation, print
├── js/main.js            # slide chrome (bg, dots, tags, n / N), zoom, lists, I-R matrix, nav
├── js/present.js         # presentation + Morph engine (View Transitions, FLIP fallback)
├── assets/               # fonts (woff2), engravings (SVG), textures (WebP), logo
├── content/              # content.md, CHANGELOG.md, ISSUES.md
├── scripts/verify-content.mjs
├── tools/                # serve, checks, tests, PDF export, standalone build, artwork generators
├── DESIGN.md · MORPH.md · SLIDES.md
└── reference/            # (git-ignored) paper-v2.pdf for verify-content
```

## Deploy

**Vercel** — Root Directory `mne-website`, framework "Other", no build command.
**GitHub Pages** — publish the `mne-website` folder with `actions/upload-pages-artifact`
(`path: mne-website`) and `actions/deploy-pages`.
