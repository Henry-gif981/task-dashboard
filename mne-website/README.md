# The Multinational Enterprises — website and slide deck

Website presenting the paper **"Multilateral Investment System and Multinational
Enterprises – Topic: The Multinational Enterprises"** (Group 4, National Economics
University – AEP, Investment Economics 65; lecturer Nguyễn Thị Mai Hoa; Ha Noi,
10/2026), **version 2** of the paper (`MNEs - Nhóm 4 (1).pdf`).

One content source, one DOM, every view in sync:

* **scroll view** — the 65 slides one under another, each a 1920×1080 stage zoomed to the
  column (reflowed below 760 px);
* **presentation** — one slide per screen, bullets revealed step by step, choreographed
  **Morph** transitions, speaker notes and a presenter window (see [MORPH.md](MORPH.md));
* **reading mode** ("Đọc", **R**) — the paper's full text as a scrolling article;
* **print / PDF** — one slide per 1920×1080 page, every bullet shown.

The slides show **bullets**; the paper's text, verbatim, is kept with every slide as `full` and shown
in the speaker notes and in reading mode.

Visual style: the vintage engraving deck *Mẫu đabien.jpg* (cream paper alternating with
blue watercolour, giant small-caps titles with cut-out engravings). See [DESIGN.md](DESIGN.md).

## Run

Requires Node.js ≥ 20.11. No dependencies to install.

```bash
cd mne-website
npm start            # → http://localhost:5173   (Present button or P key)
```

Single file that opens without a server: `python3 tools/standalone.py` → `dist/mne-website.html`.

## Content (single source)

* **`content/deck.json`** — every slide in order: id, classes, `bullets` (what the slide shows) and
  `full` (the paper's text for that slide, verbatim). **`content/slides/<id>.html`** — each slide's
  layout (tables, figures, cards) with placeholders for the bullets; prose is never written there.
  `content/shell.html` — the page around the slides. **`node tools/build.mjs`** writes `index.html`
  (do not edit `index.html` by hand; `--check` tells whether it is up to date).
* `content/COVERAGE.md` — numbers and names of the paper's text that are only in the notes, generated
  by `scripts/verify-bullets.mjs`.
* `content/content.md` — the full text of paper v2 (verbatim; tables broken by page breaks merged).
* `content/CHANGELOG.md` — what changed from paper v1 to v2, section by section (keep / edit / add / delete).
* `content/ISSUES.md` — contradictions, missing citations and calculation checks for the authors;
  the three clear cross-reference errors are corrected on the site and listed there.
* `SLIDES.md` — slide list (title, content, morph keys), generated by `node tools/slides-md.mjs`.
* Text added by the website (contents slide, key-number tiles, card labels, chart axes,
  "(cont.)", list of figures, extra abbreviations…) is marked `data-web`; bullets, ledes and shortened
  table cells are marked `data-sum` (summaries of `full`).

## Presenting

Present button, **P**, `index.html?present` or `index.html#/12` (starts on slide 12).
→ / Space / PageDown / Enter / click / swipe = next bullet, then next slide; ← = hide the last bullet,
then previous slide; Home / End, **N** speaker notes, **S** presenter window, **F** full screen,
**G** overview, **Esc** exit. The bottom bar: **Từng bước | Hiện hết**, **Cinematic | Classic | Fade | Tắt**,
"Hiệu ứng" (the eight effects one by one, speed ×0.5–2); all remembered. Durations, easings, staggers and
effect switches live in `js/morph.config.js` (MORPH.md).

## Tests (server running)

```bash
npm i -D playwright                    # once (or set PLAYWRIGHT_PATH to a global install)
node tools/build.mjs                   # content/deck.json + content/slides → index.html
node scripts/verify-bullets.mjs        # bullets add no fact absent from `full`; bullet rules; COVERAGE.md
node scripts/verify-content.mjs        # paper v2 PDF ↔ `full` texts, table cells, references
node tools/check-layout.mjs            # every slide fits 1920×1080, nothing clipped, body ≥ 22 px, tables ≥ 18 px
node tools/test-morph.mjs              # morph frames at 50 %, steps, presets, notes, presenter, reading mode
node tools/perf-morph.mjs [--all]      # frame rates of the transitions at CPU 1× / 4× (PERF.md)
node tools/shots.mjs                   # a screenshot of every slide (test-results/slides)
node tools/check.mjs                   # console errors, horizontal overflow (390/768/1440), WCAG AA contrast
node tools/screens.mjs                 # screenshots 1920×1080, 1440×900 (presentation) and 390 px (scroll)
node tools/export-pdf.mjs              # dist/mne-website.pdf, one slide per page
```

`verify-content` reads `reference/paper-v2.pdf` (not committed; put the paper there or pass
its path) and needs `pdftotext` (poppler-utils).

## Folder structure

```
mne-website/
├── index.html            # generated by tools/build.mjs (do not edit)
├── content/              # deck.json + slides/*.html + shell.html (source), content.md, CHANGELOG,
│                         # ISSUES, COVERAGE
├── css/style.css         # tokens, stage, components, bullets, reflow / reading, presentation, print
├── js/main.js            # slide chrome (bg, dots, tags, n / N), templates, zoom, reading mode, lists
├── js/morph.config.js    # durations, easings, phases, staggers, presets, effect switches
├── js/present.js         # presentation: steps, notes, presenter window, Morph engine
├── assets/               # fonts (woff2), engravings (SVG + 2× WebP), textures (WebP), logo
├── scripts/              # verify-content.mjs, verify-bullets.mjs
├── tools/                # build, serve, checks, tests, perf, PDF export, standalone, artwork
├── DESIGN.md · MORPH.md · PERF.md · SLIDES.md
└── reference/            # (git-ignored) paper-v2.pdf for verify-content
```

## Deploy

**Vercel** — Root Directory `mne-website`, framework "Other", no build command.
**GitHub Pages** — publish the `mne-website` folder with `actions/upload-pages-artifact`
(`path: mne-website`) and `actions/deploy-pages`.
